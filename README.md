# Rebel Hair Goddess V2

Dark Western salon concept based on the approved visual mockup.

## Booking link
Replace `GLOSSGENIUS_URL` in `script.js` with the client's direct booking URL. All booking buttons update from that one setting.

## Client placeholders
Replace the stylist name, address, hours, Instagram link, service details, testimonial and stock photography before launch.

## GitHub Pages
The included workflow publishes the static site automatically from `main`.
